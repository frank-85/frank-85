## Cosa costruisco

### Web app
- **Skill-Match** — Bilancio competenze + coach vocale per allenare il colloquio, 100% client-side (React + TypeScript + Web Speech API) · [🚀 Demo live](https://skill-match-tan.vercel.app) · [Repo](https://github.com/frank-85/skill-match)

### Agenti AI operativi
- **ARENA** — Simulatore di conversazioni strategiche: colloqui di lavoro, pitch a investitori, vendita B2B — tutto via Claude AI, zero infrastruttura
- **Agenti Fiducia** — Sistema di agenti basati sulla teoria dei giochi applicata alle relazioni professionali (primo contatto, onboarding, orientamento AI)
- **Skill Claude** — Comandi personalizzati che trasformano Claude Code in un partner operativo permanente

### Formazione
- **Vibe Coding Verona** — Corso pratico organizzato dai docenti del coworking "Ready Player One" per non-tecnici: costruire con l'AI senza scrivere codice tradizionale
- **Forgiatura del second brain** — Corso sperimentale organizzato dal professionista e formatore AI Mattia Calastri (https://github.com/mattiacalastri/mattiacalastri): realizzazione di una memoria persistente con funzione di Knowledge Graph su Obsidian.
